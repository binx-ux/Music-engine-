# Music

Cuebox plays local files and direct audio URLs. Put those in the Music queue if you want them in the virtual mic.

## Files and links

Drop files, paste a link, or use yt-dlp for YouTube-style URLs. Supported types include MP3, WAV, FLAC, M4A/AAC, WMA, OGG.

Shuffle and loop live on the bottom player. Loop can be off, all, or one.

## GitHub playlists

On Music, connect a GitHub repo. Cuebox looks for `cuebox.json`, `playlist.json`, m3u, txt, and folders named music / playlist / tracks. YouTube links go through yt-dlp. Raw audio files stream as URLs.

## Clean rap

**Find clean rap** searches for radio-edit / official-audio style tracks so you have something safer for voice chat. Skip anything that still looks like a mix or an explicit cut. You are still responsible for what you play.

## Soundboard

Pads on Board. Single click plays. Global hotkeys work when Cuebox is running. Presets can land in a Myinstants folder the first time you open the app.
