# Music

Search a song by name, paste a link, or drop files. Hits show up in the Find panel. Click **Get** to download and queue.

## Search

Type something like `travis scott fein clean` and hit Search. Cuebox uses yt-dlp. Click a result to pull the audio into your data folder and add it to the queue.

Paste a YouTube or direct audio URL in the same box if you already have a link.

## Files

Drop files or use Files / Folder. MP3, WAV, FLAC, M4A/AAC, WMA, OGG.

Shuffle and loop live on the bottom player.

## Clean rap

**Clean rap** looks for radio-edit style tracks for voice chat. Skip anything that still looks wrong. You are still responsible for what you play.

## GitHub playlists

Connect a public repo with `cuebox.json`, m3u, or audio files. Export writes a playlist file you can drop in a repo.

## Soundboard

Pads are on Board. One click plays. Hotkeys work while Cuebox is running.
